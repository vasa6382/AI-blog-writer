# AI Blog Writer - CrewAI Project

The complete application is located in the [`ai-blog-writer/`](./ai-blog-writer) directory.

### Quick Start:

```powershell
cd ai-blog-writer
streamlit run app.py
```

### Running Tests:

```powershell
cd ai-blog-writer
python -m pytest tests/test_blog_workflow.py -v
```

See [ai-blog-writer/README.md](./ai-blog-writer/README.md) for full instructions and [ai-blog-writer/INTERVIEW_GUIDE.md](./ai-blog-writer/INTERVIEW_GUIDE.md) for interview preparation.
